# Titanic Data Analysis Project

## Project Overview
This project analyzes the famous Titanic dataset using Python. The goal is to explore passenger data, clean the dataset, perform exploratory data analysis (EDA), create visualizations, and identify factors that influenced survival.

---

## Objectives
- Understand the structure of the dataset
- Clean and preprocess the data
- Handle missing values
- Perform exploratory data analysis (EDA)
- Visualize important patterns
- Draw meaningful insights from the data

---

## Tools and Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- OS Module

---

## Dataset Information
The dataset contains information about Titanic passengers, including:

- Passenger ID
- Survival Status
- Passenger Class
- Name
- Gender
- Age
- Family Information
- Ticket Details
- Fare
- Embarkation Point

---

## Data Cleaning Performed
- Removed the Cabin column due to a large number of missing values.
- Filled missing Age values using the mean age.
- Filled missing Embarked values using the mode (most frequent value).
- Checked for duplicate records.
- Verified data quality after cleaning.

---

## Exploratory Data Analysis (EDA)
The following analyses were performed:

- Survival count analysis
- Survival rate by gender
- Survival rate by passenger class
- Age-based survival analysis
- Family size analysis

---

## Visualizations
The project includes:

- Survival count bar chart
- Gender-wise survival rate chart
- Passenger class survival chart
- Age distribution histogram
- Fare distribution histogram

---

## Key Insights
- Female passengers had higher survival rates than male passengers.
- First-class passengers were more likely to survive.
- Age influenced survival chances.
- Family size affected passenger survival.
- Most passengers paid lower fares, while only a few paid very high fares.
